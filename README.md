# Orquestador

Herramienta local para crear sesiones de agentes de código, organizarlas como nodos en un lienzo y definir cómo colaboran entre ellas: a quién reporta cada una, qué subagentes puede invocar, qué instrucciones recibe y cuánto consume.

## Estado

En diseño. Todavía no hay código ejecutable.

## Versiones

Cada versión publicada aparece en [Releases](../../releases) con instaladores para Linux, macOS y Windows. Las versiones siguen SemVer y se generan a partir de los mensajes de commit (Conventional Commits).
